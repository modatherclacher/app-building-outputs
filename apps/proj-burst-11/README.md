# Recipe Card

An offline Flutter app that shows recipe cards with ingredient checklists and a
servings scaler. Pick a recipe, adjust servings with the +/- stepper, and every
ingredient amount rescales automatically; tick items off as you cook, with a
progress bar and a reset button. All data is in-memory, no network needed.

Run it with:

    flutter pub get
    flutter run

Tests: `flutter test`
