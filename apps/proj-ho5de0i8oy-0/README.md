# متجري الصغير

تطبيق متجر بسيط يعمل دون إنترنت بالكامل، مبني بـ Flutter وMaterial 3.

- عرض المنتجات مصنّفة في تبويبات (فواكه، خضروات، ألبان، مخبوزات، مشروبات) مع بحث وتصفية.
- سلة مشتريات مع تعديل الكميات، وإتمام الطلبات مع خصم المخزون تلقائياً، وتبويب لسجل الطلبات.
- إدارة المنتجات محلياً: إضافة وتعديل وحذف المنتجات وتحديث الكميات.

## التشغيل

1. `flutter pub get` ثم `flutter run` (لا يحتاج اتصالاً بالإنترنت).
2. للاختبار: `flutter test`
