Ring Timer is a Material 3 countdown timer for Flutter with an animated
progress ring drawn via CustomPainter. Pick a preset duration (1, 3, 5, or
10 minutes), then start, pause, resume, and reset the countdown with the
on-screen controls; the ring depletes as time passes and the app adapts to
light and dark system themes. All state is in-memory (ChangeNotifier).

Run it with:

    flutter pub get
    flutter run
