# Acoustic Soundboard

A tap-to-play Flutter soundboard where every sound is procedurally synthesized in Dart
(16-bit WAV rendered at runtime, no bundled assets) and played with audioplayers.

Funny one-shots (boing, zap, bloop, wobble, tada), lo-fi loops (keys, beat, bass, vinyl
crackle), and ambient rain beds (shower, downpour, window, thunder) can be layered and
looped at the same time. Per-sound volume and stop controls live in the Now Playing panel.

## Run

    flutter pub get
    flutter run
