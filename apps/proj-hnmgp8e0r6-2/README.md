# CarSpot

CarSpot saves where you parked with one tap, then guides you back with a live
compass, distance readout, and walking ETA. Tap "Guide me" to copy a Google
Maps or Apple Maps walking link, attach a note like "Level 3, by the elevator",
and archive the visit with "Found it" (spots you replaced or found are kept in
the history sheet).

The app runs on a simulated GPS feed because reading real location data would
require the geolocator plug-in and platform channels, which this build avoids.

## Run

```bash
flutter pub get
flutter run
```
