# Clock App

A four-tab offline clock app built with Flutter (Material 3): a live digital and analog clock, multiple addable/toggleable/deletable alarms that pop a dialog when they fire, a stopwatch with lap times, and a countdown timer with presets, pause/resume and a completion dialog. All state is in-memory; there are no platform channels or network calls.

Run with `flutter pub get` followed by `flutter run` (or `flutter test` for the smoke test).
